# 장중 급등락 모니터

장중에 짧은 주기로 스냅샷을 찍고, **평소 변동성 대비 이례적인** 움직임만 골라
원인을 웹 검색으로 확인한 뒤 텔레그램으로 보냅니다.
**미국 주식·한국 주식·해외선물 모두 한국투자증권 KIS OpenAPI** 하나로 받습니다.

```
monitor.py                     본체 (--market us | kr | fut)
kis.py                         KIS OpenAPI 래퍼 (국내주식·해외주식·해외선물)
requirements.txt               requests + anthropic 뿐
.github/workflows/intraday-us.yml
.github/workflows/intraday-kr.yml
.github/workflows/intraday-fut.yml
```

## 시세가 실시간인가 — 주식과 선물이 다릅니다

KIS 공식 문서에 명시돼 있습니다.

> 지연시세 지연시간 : **미국 — 실시간무료(0분지연)** / 홍콩, 베트남, 중국, 일본 — 15분지연

즉 미국 종목은 별도 신청이나 추가 비용 없이 실시간으로 받습니다. 아시아 시세만
15분 지연이고 이 모니터는 아시아를 보지 않습니다. 같은 문서에 **"미국의 경우 장중
당일 시가는 상이할 수 있으며 익일 정정 표시됩니다"** 라는 단서가 있어, 시가가 아니라
**전일종가(base)** 를 기준으로만 등락률을 계산합니다.

**해외선물은 이야기가 다릅니다.** 같은 저장소에 이렇게 적혀 있습니다.

> ※ CME, SGX 실시간시세 **유료시세 신청 필수**

다만 이 문구는 **웹소켓 실시간 체결가/호가** 쪽에 달려 있고, 이 모니터가 쓰는
**REST 현재가(inquire-price)** 가 지연인지 실시간인지는 문서에 명시가 없습니다.
확인할 방법이 없어 추측하는 대신, 응답의 `proc_date`/`proc_time`(최종처리일시)을
현재 시각과 비교해 **실제 지연을 직접 재서 로그에 남기도록** 했습니다.

```
선물 시세 지연 측정: 최종처리 20260921 093012 → KST 기준 +0분. 실시간으로 보입니다
선물 시세 지연 측정: 최종처리 20260921 091812 → KST 기준 +12분. 지연 시세입니다 — 순간급변 탐지는 그만큼 늦습니다
```

첫 실행 로그에서 둘 중 하나가 찍힙니다. **지연으로 나오면** 선물의 순간급변 탐지는
그만큼 늦게 도착하므로, 유료시세를 신청하든지 선물은 일중 누적 경로(그래도 유효합니다)
만 쓰든지 정하시면 됩니다. CME·ICE API 시세비용은 KIS 공지에 별도로 올라오는데
저는 그 공지 본문을 열지 못했습니다. 금액은 KIS 포털 FAQ("해외선물옵션 API 유료시세
신청방법")에서 확인하세요.

## 감시 주기

깨어 계신 한국장은 촘촘하게, 주무시는 미국장은 개장 직후에만 촘촘하게 봅니다.

| | 구간 | 주기 | 후보 |
|---|---|---|---|
| 한국 | 09:00~15:35 KST 내내 | 60초 | 등락률 순위 상하위 + 추적분 + 관심종목 |
| 미국 | 09:30~12:25 ET | 60초 | 3개 거래소 등락률·거래량급증 순위 + 관심종목 |
| 미국 | 12:26~16:00 ET | **1시간** | 같음 (순위 깊이 2배) |
| 해외선물 | 09:00~15:35 KST | 60초 | 지정 품목의 근월물 (아시아 시간 ES·NQ) |
| 해외선물 | 09:30~12:25 ET | 60초 | 같음 (= 22:30~01:25 KST, 깨어 있을 수 있는 구간) |
| 해외선물 | 12:26~16:00 ET | **1시간** | 같음 |

미국과 해외선물은 **개장 후 3시간까지 60초, 그 뒤 마감까지 1시간에 한 번**으로
같은 모양입니다. 잠든 시간이라 촘촘히 볼 이유는 없지만, 놓치면 아침에 영문을
모르게 되므로 완전히 비우지는 않았습니다. 서머타임 양쪽 모두 13:00 / 14:00 /
15:00 / 16:00 ET 네 번 돕니다.

전 종목을 훑지 않습니다. KIS 등락률 순위와 거래량급증 순위가 이미 "지금 크게
움직이는 것"을 골라 주므로, 거기에 **항상 보는 관심종목**과 **한 번이라도 순위에
들었던 종목(추적분)** 을 더합니다. 대형주는 8% 급락해도 등락률 순위 상위에는 못
드는 날이 많아, 관심종목이 그 구멍을 메웁니다.

해외선물(CME Globex)은 일요일 18:00 ET ~ 금요일 17:00 ET 까지 거의 24시간 돌지만
전 구간을 1분으로 보지는 않습니다. 비어 있는 곳은 한국 저녁(=미국 새벽) 한 군데뿐인데,
거래가 얇아 알림 가치가 낮습니다. 그 구간도 보시려면 `intraday-fut.yml` 에
04:00 / 10:00 UTC 루프 잡을 같은 형태로 추가하시면 됩니다.

**중요 — cron 으로는 1분 간격이 불가능합니다.** GitHub Actions 의 `schedule` 은
최소 간격이 5분이고, 그마저 5~15분씩 밀립니다. 그래서 크론을 자주 도는 대신
**한 번 깨어나 60초 루프를 도는 장시간 잡** 구조로 만들었습니다. 잡 하나의
최대 수명이 6시간이라 한국은 오전/오후 두 잡으로 나눕니다.

## 탐지 기준

단순 등락률만 쓰면 원래 변동성이 큰 종목이 매일 걸립니다. 두 경로 중
**하나라도** 걸리면 알립니다.

**(A) 일중 누적** — 아침부터 지금까지의 움직임

| 조건 | 기본값 | 이유 |
|---|---|---|
| 절대 등락률 | ±4% 이상 | 통계적으로 이례적이어도 폭이 작으면 볼 필요 없음 |
| z (일간 변동성 대비) | 3.0σ 이상 | 그 종목 기준으로 이례적인가 |
| 거래량 배수 | 같은 시각 평소의 1.8배 | 가격만 튀고 거래가 없으면 호가 공백일 뿐 |

**(B) 순간 급변** — 최근 5분 사이의 움직임. **1분 폴링의 존재 이유입니다.**

| 조건 | 기본값 | 이유 |
|---|---|---|
| 5분 변동폭 | ±2% 이상 | |
| z (해당 구간 환산 변동성 대비) | 3.5σ 이상 | 일간 σ 를 √(측정구간/390분) 으로 환산 |
| 그 5분 구간의 거래량 | 평소 같은 길이의 1.8배 | 누적거래량 차분으로 계산 |

(A) 만 보면 **갭상승 후 종일 횡보하는 종목이 계속 걸립니다.** (B) 는 지금 막
벌어지는 것만 잡아냅니다. 알림에 `순간급변` / `급변+누적` / `누적` 으로 어느
경로에 걸렸는지 표시되고, 순간급변이 먼저 정렬됩니다.

폴링이 밀려 측정 구간이 5분이 아니라 8분이 되면 **임계치도 그 길이로 다시
환산**합니다. 그러지 않으면 구간이 넓어질수록 임계가 저절로 헐거워집니다.
체결 이력은 `state/` 에 저장해 실행 간에 넘기므로, 30분 단발 스캔에서도
직전 스캔 대비 순간 변동을 잴 수 있습니다.

일간 변동성과 평균거래량은 **오늘 자 봉을 뺀** 최근 20영업일로 구합니다.
오늘 봉을 넣으면 지금 잡으려는 급등이 제 자신의 σ 를 키워 z 를 눌러버립니다.

여기에 같은 종목 **120분 재알림 금지**, 1회 스캔 4건 / **시간당 8건 / 하루 40건**
상한이 걸립니다. 1분 루프에서는 상한이 없으면 변동성 큰 날 API 비용이 그대로
늘어납니다.

원인 분석은 일일 귀인과 같은 원칙입니다. 날짜가 확인되는 사실만 쓰고, 확인되지
않으면 **"확인된 촉발 사건 없음"** 으로 둡니다. 장중에는 원인이 아직 보도되지 않은
경우가 흔하므로 이것이 정상적인 결과입니다.

## 1. 한국투자증권 KIS OpenAPI 발급

**계좌가 먼저 있어야 합니다.** 본인 명의 한국투자증권 계좌를 개설하세요
(비대면 개설 가능, 신분증·본인명의 휴대폰 필요).

1. [KIS Developers](https://apiportal.koreainvestment.com) 접속 → 회원가입
   - 계좌번호 8자리 + 상품코드 2자리, 휴대폰 또는 공동인증서로 본인확인
   - 이메일 인증 링크로 활성화
2. **개인 → 인증키 발급** 메뉴에서 앱 등록
   - **실전 키를 쓰세요.** 모의투자 환경은 해외 시세·순위 API 가 제한됩니다
     (주문 API 를 쓰지 않으므로 실전 키라도 매매는 일어나지 않습니다).
3. **APP KEY** (약 36자) 와 **APP SECRET** (약 180자) 를 받습니다.
4. 해외주식 시세를 처음 쓰신다면 HTS/MTS 에서 **해외주식 시세 이용 신청**이
   되어 있는지 확인하세요. 미국은 무료 실시간이지만 이용 동의가 필요합니다.

| 환경 | 도메인 |
|---|---|
| 실전 | `https://openapi.koreainvestment.com:9443` |
| 모의 | `https://openapivts.koreainvestment.com:29443` |

접근토큰은 24시간 유효합니다. 매번 새로 받으면 발급 한도(EGW00133)에 걸리므로
`state/kis_token.json` 에 캐시해 재사용합니다. 유량 제한은 실전 초당 20건이고,
래퍼가 락으로 초당 ~16건까지만 나가도록 직접 조절합니다.

### 쓰는 엔드포인트

전부 KIS 공식 저장소(`koreainvestment/open-trading-api`)의 예제에서 확인한
값입니다. 추측이 아닙니다.

| 용도 | 경로 | tr_id |
|---|---|---|
| 국내 등락률 순위 | `/uapi/domestic-stock/v1/ranking/fluctuation` | `FHPST01700000` |
| 국내 현재가 | `/uapi/domestic-stock/v1/quotations/inquire-price` | `FHKST01010100` |
| 국내 일봉 | `.../inquire-daily-itemchartprice` | `FHKST03010100` |
| 해외 등락률 순위 | `/uapi/overseas-stock/v1/ranking/updown-rate` | `HHDFS76290000` |
| 해외 거래량급증 | `/uapi/overseas-stock/v1/ranking/volume-surge` | `HHDFS76270000` |
| 해외 현재체결가 | `/uapi/overseas-price/v1/quotations/price` | `HHDFS00000300` |
| 해외 일봉 | `/uapi/overseas-price/v1/quotations/dailyprice` | `HHDFS76240000` |
| 해외선물 현재가 | `/uapi/overseas-futureoption/v1/quotations/inquire-price` | `HHDFC55010000` |
| 해외선물 일봉 | `/uapi/overseas-futureoption/v1/quotations/daily-ccnl` | `HHDFC55020100` |

함정 하나: **해외 순위의 `GUBN` 은 1=상승률, 0=하락률로 국내와 반대**입니다.

### 해외선물은 순위 API 가 없습니다

주식과 달리 "오늘 많이 오른 선물" 을 뽑아 주는 API 가 없어서, **볼 품목을 정해 두고
근월물을 매일 자동으로 찾습니다.** 종목코드는 `ROOT + 월물코드 + 2자리연도`
(예: 금 2026년 12월물 = `GCZ26`) 이고, 품목마다 상장월이 달라 월물표를 들고 있기보다
가까운 월부터 실제로 조회해 보고 **잔존일수가 `FUT_ROLL_DAYS`(기본 4일) 이상인
첫 월물**을 씁니다. 하루 한 번만 찾고 `state/fut_symbols.json` 에 캐시합니다.

쿨다운과 체결 이력은 월물이 아니라 **품목 단위**(`GC`, `ES` …)로 겁니다. 그리고
**롤오버로 월물이 바뀌면 그 품목의 이력을 버립니다** — 월물이 달라지면 가격 수준이
점프하는데 이력을 이어 두면 롤을 '순간 급변'으로 오인합니다.

기본 품목은 `ES,NQ,CL,NG,GC,SI,HG,ZC,ZS,ZW,ZN,6E,6J` (S&P500·나스닥100·WTI·천연가스·
금·은·구리·옥수수·대두·밀·미국10년물·유로·엔) 이고 `FUT_ROOTS` 로 바꿉니다.
알림에는 한글 품목명으로 표시됩니다.

선물은 세션이 23시간이라 **순간급변 임계를 √(구간/1380분)으로 환산**합니다.
주식의 390분을 그대로 쓰면 임계가 1.9배 헐거워져 오탐이 쏟아집니다.
일중 누적 거래량비는 18:00 ET 에 하루가 바뀌는 구조 탓에 경과 비율 계산이 꼬이기
쉬워 **쓰지 않습니다**(근월물은 유동성이 충분해 '호가 공백' 걱정이 적습니다).
순간 구간 거래량비는 세션 길이만 있으면 되므로 그대로 작동합니다.

## 2. GitHub Actions 설정

### 저장소 만들기
새 저장소를 **공개(Public)** 로 만들고 이 폴더의 파일을 그대로 올립니다
(`.github/workflows/` 경로 유지). 공개로 하는 이유는 아래 무료 한도 항목에 있습니다.

### 시크릿 등록
저장소 → **Settings → Secrets and variables → Actions → New repository secret**

| 이름 | 필수 | 비고 |
|---|---|---|
| `KIS_APP_KEY` | ✅ | 미국·한국 공용 |
| `KIS_APP_SECRET` | ✅ | 〃 |
| `ANTHROPIC_API_KEY` | ✅ | [platform.claude.com/settings/keys](https://platform.claude.com/settings/keys) |
| `ANTHROPIC_WORKSPACE_ID` | 조건부 | 조직 범위 키일 때만 (`wrkspc_...`) |
| `TELEGRAM_TOKEN` | ✅ | 기존 봇 토큰 재사용 가능 |
| `TELEGRAM_CHAT_ID` | ✅ | 〃 |
| `KR_WATCHLIST` | 선택 | `005930,000660,035720` 형식 |
| `US_WATCHLIST` | 선택 | `NVDA,TSM,SPY` 형식. 비우면 기본 목록 사용 |
| `FUT_ROOTS` | 선택 | `ES,NQ,GC,CL` 형식. 비우면 기본 13품목 |

**관심종목도 Variables 가 아니라 Secrets 에 넣으세요.** 공개 저장소에서는
Variables 가 로그에 평문으로 남지만 Secrets 는 `***` 로 마스킹됩니다.

### 공개 저장소에서 무엇이 가려지나

워크플로에 `QUIET_LOG: "1"` 이 들어 있습니다. 이걸 켜면 알림 **건수만** 로그에
남고 종목코드·등락률은 남기지 않습니다. 정리하면 이렇습니다.

| 항목 | 공개 로그에 | 
|---|---|
| API 키·토큰·텔레그램 토큰 | `***` 마스킹 |
| 관심종목 목록 (Secrets 로 넣었을 때) | `***` 마스킹 |
| 어떤 종목이 걸렸는지 | `QUIET_LOG=1` 이면 안 남음 |
| 알림 본문·원인 분석 | 애초에 로그로 안 나가고 텔레그램으로만 감 |
| 스캔한 종목 수, 알림 건수, 오류 | 남음 (민감하지 않음) |

즉 공개 저장소라도 **무엇을 보는지·무엇이 걸렸는지는 드러나지 않습니다.**
다만 저장소에 이 코드가 공개된다는 점, 그리고 하루 몇 건이 걸렸는지 같은
빈도 정보는 보인다는 점은 남습니다.

### cron 이해하기

`on.schedule.cron` 은 **UTC 기준**이고 필드는 `분 시 일 월 요일` 입니다.

```yaml
- cron: "30 13 * * 1-5"   # UTC 13:30, 월~금  (= 서머타임 중 09:30 ET)
```

서머타임 때문에 미국장 09:30 ET 는 UTC 로 13:30(EDT) 또는 14:30(EST) 입니다.
cron 은 서머타임을 모르므로 **두 시각 모두 걸어두고**, `--skip-if-after 10:15`
으로 "이미 다른 잡이 맡은 구간이면 즉시 종료" 시킵니다. 선물은 08:30 ET 에도 장이 열려 있어 `--skip-if-before 09:30` 가드가 하나 더 붙습니다. 해당 없는 쪽은 몇 초 만에
끝납니다. 같은 이유로 2단계(30분 주기)는 UTC 16~21시를 전부 덮고
`--skip-if-before 12:26` 으로 1단계와 겹치는 구간을 잘라냅니다.

알아두실 점 셋입니다. GitHub cron 은 **정시 보장이 없어** 5~15분 지연됩니다
(루프 안에서는 영향 없고, 잡이 뜨는 시각만 밀립니다). **60일간 커밋이 없으면
스케줄이 자동 비활성화**되니 가끔 커밋하거나 Actions 탭에서 다시 켜 주세요.
그리고 **잡 하나는 6시간에 강제 종료**되므로 `--max-minutes` 로 그 전에 스스로
빠져나오게 해 두었습니다.

### 무료 한도

| | 분/일 | 분/월(21영업일) |
|---|---|---|
| 한국 (오전 180 + 오후 215) | 약 400 | 약 8,400 |
| 미국 (루프 175 + 1시간 단발 4회) | 약 187 | 약 3,900 |
| 해외선물 (175 + 215 + 175 + 단발 4회) | 약 573 | 약 12,000 |
| **합계** | | **약 24,300** |

비공개 저장소 무료 한도는 월 2,000분, 초과분은 Linux 기준 분당 $0.006 이라
그대로 돌리면 월 $134 정도가 붙습니다. **공개 저장소는 Actions 분이 무제한**이라
비용이 0입니다. 상시 켜 둘 장비(본인 PC, 소형 VPS)가 있다면 셀프호스티드 러너를
붙이는 방법도 있고, 그 경우 비공개 저장소에서도 Actions 분을 쓰지 않습니다.

공개 저장소라 분이 무제한이므로, 원하시면 미국도 마감까지 60초 루프로 늘릴 수
있습니다 (`intraday-us.yml` 의 `--loop-until` 을 15:55 로, 2단계 잡 삭제).
지금은 "자는 시간에는 30분이면 충분하다"는 전제로 나눠 두었습니다.

### 첫 실행 확인 — 주말에도 됩니다

Actions 탭에서 워크플로를 고르고 **Run workflow** → **"장 시간을 무시하고 즉시
1회 스캔" 체크** → 실행하세요. 장이 닫힌 주말에도 돌고, 루프가 아니라 단발이라
2~3분이면 끝납니다. 이 한 번으로 아래가 전부 확인됩니다.

- KIS 토큰 발급 (`KIS 토큰 신규 발급` 로그)
- 시세·순위 API 권한 (`KIS 오류 [tr_id] ...` 가 뜨면 권한 문제)
- 해외선물이면 시세 지연 여부 (`선물 시세 지연 측정: ...`)
- 텔레그램 전송 (기준 충족 종목이 있으면 메시지가 옵니다)

체크를 안 하고 실행하면 평소처럼 장 시간을 보고 `장 시간 아님 → 종료` 로 끝납니다.
로컬에서 돌려 보실 수도 있습니다.

```bash
pip install -r requirements.txt
export KIS_APP_KEY=... KIS_APP_SECRET=...
export ANTHROPIC_API_KEY=... TELEGRAM_TOKEN=... TELEGRAM_CHAT_ID=...

python monitor.py --market us --force                   # 단발
python monitor.py --market us --force --universe full   # 순위 2배 깊게
python monitor.py --market kr --force \
       --loop-until 15:35 --interval 60                 # 루프 (KST 기준)
python monitor.py --market fut --force                  # 해외선물 단발
python monitor.py --market fut --force \
       --loop-until 16:00 --interval 60                 # 선물 루프 (ET 기준)
```

`--force` 는 장 시간 검사를 건너뜁니다. 텔레그램 토큰이 없으면 전송 대신
화면에 그대로 출력하므로, 문구만 확인하실 때 편합니다. 처음 돌릴 때는
`QUIET_LOG` 를 켜지 말고 어떤 종목이 걸리는지 눈으로 확인해 보세요.

## 3. 임계 조정

워크플로의 `env` 에서 바꿉니다. 처음에는 기본값보다 **높게** 잡아 알림을 적게
받아보고, 놓치는 게 있다 싶을 때 낮추는 편이 낫습니다.

| 변수 | 기본 | 설명 |
|---|---|---|
| `Z_THRESHOLD` | 3.0 | 일중 누적 경로. 낮출수록 알림 급증 |
| `MIN_ABS_PCT` | 4.0 | 최소 등락률(%) |
| `VOL_RATIO_MIN` | 1.8 | 거래량 동반 조건 |
| `BURST_MIN` | 5 / 60 | 순간 변동 측정 구간(분). **스캔 간격에 맞추세요** — 60초 루프는 5, 1시간 단발은 60 |
| `BURST_Z` | 3.5 | 순간 경로 임계. **알림이 너무 많으면 여기부터 올리세요** |
| `BURST_MIN_PCT` | 2.0 | 순간 변동 최소 폭(%) |
| `MAX_ALERTS` | 4 | 1회 스캔당 상한 |
| `MAX_PER_HOUR` | 8 | 시간당 상한 |
| `MAX_PER_DAY` | 30 / 20 / 10 | 하루 상한. 한국 / 미국 / 선물 (**비용을 묶는 핵심 손잡이**) |
| `COOLDOWN_MIN` | 120 | 같은 종목 재알림 금지(분) |
| `RANK_N` | 20 | 순위에서 가져올 종목 수 (방향·거래소별) |
| `SURGE_N` | 10 | 거래량급증 순위에서 가져올 수 (미국) |
| `TRACK_MAX` | 40 | 순위에서 빠진 뒤에도 계속 볼 종목 수 |
| `VOL_RANG` | 3 | 해외 순위 거래량 조건 (3=1만주 이상) |
| `WORKERS` | 4 | 개별 현재가 동시 조회 수 |
| `FUT_ROLL_DAYS` | 4 | 잔존일수가 이보다 적으면 다음 월물로 |
| `QUIET_LOG` | 0 | 1이면 로그에 종목명을 남기지 않음 |

선물은 주식보다 변동폭이 작아 워크플로에서 임계를 따로 낮춰 뒀습니다
(`MIN_ABS_PCT` 2.0, `BURST_MIN_PCT` 1.0, `BURST_Z` 4.0). 주식 기준 4% 를 그대로
쓰면 선물은 거의 아무것도 걸리지 않습니다.

로그에 `주의: 스캔 1회에 NN초` 가 뜨면 한 바퀴가 간격보다 오래 걸린다는 뜻입니다.
관심종목이나 `TRACK_MAX` 를 줄이거나 `WORKERS` 를 6~8로 올리세요.

## 비용

KIS 시세는 무료이고 GitHub Actions 도 공개 저장소면 0원이라, 드는 것은 Anthropic
API 뿐입니다. Sonnet 5 가 입력 $2 / 출력 $10 per MTok, 서버측 웹 검색이 1,000회당
$10 입니다.

알림은 한 묶음(여러 종목을 한 번에 조사)으로 나갑니다. 4종목 묶음 기준 검색 8회
$0.08, 검색 결과가 대화에 누적되며 쌓이는 입력 약 10만 토큰 $0.20, 출력 $0.02 —
**묶음당 약 $0.30** 입니다.

| | 하루 상한 | 최대 묶음/일 | 월 상한(21영업일) |
|---|---|---|---|
| 한국 | 30건 | 8 | 약 $50 |
| 미국 | 20건 | 5 | 약 $32 |
| 해외선물 | 10건 | 4 | 약 $25 |
| **합계** | | **17** | **약 $107** |

이것은 **상한을 매일 다 쓰는 최악의 경우**이고, 보통은 하루 5~8묶음이라 월 $35~55
수준입니다. 여기에 기존 일일 귀인이 월 $12 내외로 따로 붙습니다.

비용을 더 줄이려면 순서대로 이렇습니다. `MAX_PER_DAY` 는 절대 상한이라 원하는
금액에 정확히 맞출 수 있습니다(위 표에서 묶음당 $0.30 을 곱하시면 됩니다).
`SEARCH_PER_NAME` 을 2→1 로 낮추면 검색 비용과 누적 입력 토큰이 같이 줄어 체감이
큽니다. `ATTRIB_MODEL` 을 Haiku 로 바꾸면 토큰 단가가 절반이지만 원인 분석 품질은
떨어집니다.

## 알려진 한계

- **컨테이너에서 KIS 에 접속할 수 없어 실호출 검증은 못 했습니다.** 엔드포인트와
  tr_id·파라미터·응답 필드는 KIS 공식 저장소 예제에서 그대로 가져왔고, 파싱·판정
  로직은 가짜 응답으로 75개 항목을 검증했습니다. 실제 응답이 다르면 로그에
  `KIS 오류 [tr_id] msg_cd: ...` 가 한 번 찍히도록 해 두었으니 그 줄을 보내주세요.
- **미국 후보는 순위 기반**이라, 순위에 들지 않는 종목은 관심종목에 없으면 놓칩니다.
  기본 관심종목에 대형주·섹터 ETF·반도체를 넣어 두었고 `US_WATCHLIST` 로 교체할
  수 있습니다.
- 순위에 갓 진입한 종목은 직전 시세 이력이 없어 **첫 5분간은 순간급변 판정을 못 하고**
  일중 누적 경로로만 걸립니다. 한 번 순위에 든 종목은 빠진 뒤에도 `TRACK_MAX` 개까지
  계속 추적해 이력을 잇습니다.
- **해외선물 REST 시세의 지연 여부는 확인되지 않았습니다.** 첫 실행 로그의 '지연 측정'
  줄을 보시고, 지연으로 나오면 유료시세 신청 여부를 판단하세요. 미국 주식은 공식
  문서에 실시간 무료라고 명시돼 있어 이 문제가 없습니다.
- 해외선물은 **ICE 상품(브렌트유, 달러인덱스)이 기본 품목에 없습니다.** CME 와 시세
  계약이 달라 별도로 확인이 필요합니다. `FUT_ROOTS` 에 추가해 보시고 근월물을 못
  찾으면 권한 문제입니다.
- 선물 옵션은 다루지 않습니다. KIS 에 API 는 있습니다(`opt_price` 등).
- 시가 갭은 순간급변으로 잡히지 않습니다. 개장 전 이력이 없기 때문이며, 갭은
  일중 누적 경로가 담당합니다.
- 해외 종목의 거래소(NAS/NYS/AMS)는 코드만으로 알 수 없어 처음 한 번 탐색해
  `state/us_excd.json` 에 적어 둡니다. 상장 이전이 있으면 그 파일을 지우세요.
- 로직 검증은 가짜 응답 기준 **118개 항목**이 통과했습니다. 실호출 검증은 여전히
  못 했습니다.
